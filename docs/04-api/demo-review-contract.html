Hợp đồng demo review (M-DEMO01)

DEMO-ONLY. Chốt một lần để Nam (D-01, D-03) và Việt Anh (D-02, D-04) làm song song. Đổi hợp đồng phải báo cả hai và ghi vào Progress Notes của M-DEMO01.

Nguyên tắc để không chờ nhau

  • Không có bảng mới để lưu hạng. API (D-03) tính hạng khi đọc: lấy CandidateRecord của run, gọi ranking.score_v0.rank_frames trên mọi frame của snapshot. Nhờ đó D-03 không phụ thuộc cách D-02 lưu dữ liệu.
  • Nguồn dữ liệu có sẵn trên develop: SnapshotFrame.shapes (shape + ảnh), orchestration.CandidateRecord (candidate, evidence), runs.EngineResult (trạng thái engine). Orchestrator (T-025) và engine Schema/Geometry (T-027) đã có.
  • Fixture dùng chung: src/frontend/src/lib/demo/frames.fixture.json. D-04 làm UI hoàn toàn trên fixture; D-03 trả đúng hình dạng fixture.

GET /api/runs/{run_id}/frames

Query: cursor, page_size (mặc định 50). Quyền: Reviewer / QA Lead / Super Admin có scope dataset của run; vai trò khác 403. Chưa đăng nhập 401.
