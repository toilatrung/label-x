CI/CD và kiểm thử toàn bộ giai đoạn LabelX

Thiết kế kiểm thử và workflow khung, dựa trên stack DEC-001 và các quyết định đã chốt. Không tự triển khai sản phẩm hoặc mở rộng scope SRS M13.

1. Kết luận

  1. 12 nhóm giai đoạn và 62 ca kiểm thử, có truy vết R-01–R-07/FR/AC/NFR.
  2. Hiện chỉ một ca nghiệp vụ scaffold có mã smoke OpenAPI; chưa có adapter/engine/review/ranking, frontend chưa có test runner. Lint/build không thay E2E.
  3. CI chạy trên PR/main: framework, lint/types, migration/schema, PostgreSQL smoke và Next build. Pipeline chưa có run GitHub thực trong workspace này.
  4. Gate từ chối test chưa bind, zero/all-skipped, commit/provenance sai, policy/reference TBD. Kết quả dự kiến của phase chưa xây là BLOCKED, không phải pass.
  5. CD chưa có target/hook/approval môi trường; scaffold xanh không cho deploy MVP hoặc phát hành Dataset.
Nguồn: src/backend/tests/test_smoke.py; src/frontend/package.json; DEC-001; test-matrix.json; .github/workflows/*.yml. Mã kiểm cổng CI có bộ test riêng, không tính là test nghiệp vụ.

2. Luồng CI/CD

PR → CI/checks → build artifact theo commit → phase tests/reference/evaluation → review QA → staging smoke/migration rehearsal → approval → production hook → smoke/rollback.

Deployment phần mềm khác phát hành Dataset. M13 chỉ hiển thị gate (SRS FR-GTE-04). RAG/Temporal/Classifier/full release sau MVP phải có scope được duyệt; VLM pilot còn TBD-08 trong SRS dự thảo.

5. Dữ liệu, accuracy và kiểm thử thực tế

PR dùng ảnh/annotation tổng hợp và mock/stub; không báo accuracy thật từ fixture. PostgreSQL/worker/Object Storage thật cần cho transaction/retry; eager task hoặc SQLite không chứng minh hệ phân tán.

Nguồn: T mục 6–8; SRS FR-EVL-01…16, AC-08/09, NFR-01…03; quyết định B-05/B-14/B-20.

6. Cổng CI/CD và bằng chứng

Receipt mỗi phase lưu commit, hash plan, danh sách case và hash JUnit. Gate yêu cầu test không skip, đủ case, dependency passed và cùng commit. CD chỉ nhận CI/phase workflow success từ main, cùng SHA; không nhận PR run hoặc report cũ.

GitHub environment cần required reviewers/prevent self-review; bảo vệ main và runner dữ liệu. Cơ chế kiểm receipt không thay QA độc lập hoặc quyết định phê duyệt. Không log/upload ảnh, token, held-out hay prompt riêng.

Nguồn: scripts/ci/quality-gate.cjs; CI/CD workflows; AGENT.html; GitHub environments.
