Context

Bản rà soát docs/00-project/sources/architecture_review.html (05/10/2026) ghi nhận người dùng đã chốt 21/21 mục B-01–B-21 và cấu hình MVP sáu mục ("Chốt phương án MVP này"). Backend, worker và kho dữ liệu đã chốt; frontend không được nêu trong bản rà soát và được người dùng chốt riêng trong phiên ngày 2026-10-05: "frontend thì dùng nextjs".

Decision Drivers

  • Modular monolith + worker pool, worker kiểm xác định/model tách khỏi API (B-01).
  • Adapter CVAT chỉ đọc; sửa annotation bằng deep link sang CVAT (B-18).
  • Task phải idempotent dù có retry; quyền project/job kiểm ở API (B-10, B-12).
  • Snapshot, evidence, report/manifest lưu bất biến trên Object Storage hiện có.

Options Considered

Option Benefits Costs and Risks Constraint Fit
Django + DRF, PostgreSQL, Celery + Redis, Object Storage Khớp sơ đồ L (Django/DRF modular monolith); admin, ORM, permission sẵn Phải giữ task idempotent; Celery cần vận hành Redis meets
FastAPI Đội có thể đã quen Chỉ giữ nếu backend FastAPI hiện có được xác minh; chưa có bằng chứng partially-meets
Next.js (App Router, TypeScript) cho frontend Người dùng chốt; SSR/route typing; dùng được CSS lx-* của Design System Next 16 có thay đổi API so với bản cũ meets

Decision Outcome

  • Selected Option: Backend Django 5.2 LTS + Django REST framework + drf-spectacular (OpenAPI); PostgreSQL 17; Celery 5 + Redis 7 (broker/result, django-celery-beat); Object Storage S3-compatible qua django-storages (SeaweedFS chỉ cho dev local); frontend Next.js 16 + React 19 + TypeScript, TanStack Query, openapi-fetch/openapi-typescript sinh type từ OpenAPI; Design System LabelX (tokens.css + bundle.css). Python 3.12 quản lý bằng uv; Node >= 22 với npm. Mã nguồn ở src/backend và src/frontend, hạ tầng dev ở infrastructure/.
  • Rationale: Đúng cấu hình MVP đã chốt trong docs/00-project/sources/architecture_review.html; frontend theo chỉ định của người dùng. Ngoại lệ FastAPI không áp dụng vì repository chưa có backend.
  • Effective Date: 2026-10-05

Consequences

  • Positive: Một hợp đồng OpenAPI duy nhất sinh type cho frontend; dev mới cài toàn bộ bằng make setup.
  • Negative: Chưa pin phiên bản CVAT/cvat-sdk; phải pin sau khi kiểm API instance thật. Frontend chưa có test runner (vitest bị loại khỏi scaffold do lỗi npm peer-set) — chọn lại khi có epic frontend.
  • Follow-up Work: none
