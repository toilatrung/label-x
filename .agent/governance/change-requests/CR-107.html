Proposed Change

Trước: E-03 scope “RulesThresholds phần mapping nhóm lỗi/lớp → rule ID (QC Admin sửa, vai trò khác chỉ xem)”; T-017 “API sửa có kiểm hợp lệ”.

Sau: mapping nạp từ tệp, kiểm hợp lệ khi nạp (rule ID tồn tại, lớp thuộc taxonomy, family thuộc IssueFamily, không trùng; tệp lỗi bị từ chối toàn bộ và báo dòng lỗi); màn RulesThresholds phần mapping chỉ xem cho mọi vai trò được đọc; không có API sửa mapping.

Justification

CR-101 đặt mapping nhóm lỗi/lớp → rule ID trong tệp guideline tĩnh nạp lúc khởi tạo, nên “QC Admin sửa” trên màn mâu thuẫn với nguồn sự thật là tệp. FR-GDL-02 (should, “QC Admin cấu hình mapping (nhóm lỗi, lớp, cặp lớp) → rule ID”) được đáp ứng ở pilot bằng cách nạp tệp mapping có kiểm hợp lệ (gồm cặp lớp paired_class), không có UI hay API sửa. Thao tác nạp vẫn là thay đổi cấu hình nên phải có dấu vết theo FR-SEC-05: lệnh nạp bắt buộc --actor và lưu bản ghi load bất biến; T-017 không phụ thuộc T-013, ghi vào audit chung là follow-up của T-013.
