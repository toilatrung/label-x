Proposed Change

Trước: giai đoạn A dùng Gemini (gemini-3.8-flash) làm VLM. Sau: dùng Qwen3-VL qua DashScope API (endpoint tương thích OpenAI), model mặc định qwen3-vl-plus, đặt trong models.vlm của ConfigVersion. Giai đoạn B (ConvNeXt Tiny) và C (routing) giữ nguyên; chỉ đổi tên engine VLM.

  • Adapter đọc provider, model, base_url, prompt_version, timeout, max attempts và budget từ config; model ID phải thuộc allowlist trong source.
  • Dùng bản Instruct, không dùng chế độ suy luận; bỏ cấu hình "thinking thấp".
  • JSON theo schema nội bộ; nếu model không hỗ trợ JSON schema thì validate phía backend và chuyển uncertain hoặc failed parse.
  • FE vẫn không gửi prompt, API key, model ID hay ảnh.

Justification

Product Owner chọn Qwen làm VLM. Qwen3-VL có các cỡ 2B–235B và dùng được cả qua API lẫn tự host, nên đổi hosting sau này chỉ cần đổi base_url.

Impact Assessment

  • Affected Baselines: .agent/planning/{roadmap,milestones,epics}.html; M-04-ABC; docs/12-ai/vlm.html; docs/04-api/openapi.yaml
  • Affected Tasks: M04A-01, M04A-02, M04A-05, M04C-01, M04C-03, M04C-04, M04S-01
  • Cost or Resource Impact: DashScope API key/quota/cost; không cần GPU cho VLM.
  • Security or Compliance Impact: Crop ảnh gửi ra DashScope (Alibaba Cloud) chỉ khi policy dữ liệu cho phép; cần xác nhận region endpoint và điều khoản dữ liệu trước smoke thật. Secret chỉ ở runtime config.
  • Compatibility: Chưa có code Gemini; evidence lưu model/prompt version theo contract CR-115 nên không cần migration.

Open Items

  • Xác nhận model ID, region base URL và hỗ trợ JSON schema của qwen3-vl-plus/qwen3-vl-flash với tài liệu chính thức Alibaba Model Studio (chưa kiểm chứng từ nguồn chính thức).
  • Xác nhận quyền gửi crop và quota; không có credential nào được ngầm cho phép bởi CR này.
  • Cập nhật docs/12-ai/vlm.html và openapi.yaml khi tồn tại nội dung Gemini.
