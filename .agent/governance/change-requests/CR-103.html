Proposed Change

Trước: Markdown (.md có YAML frontmatter) là nguồn của mọi tài liệu trong docs/, .agent/ và AGENT.md; HTML được sinh từ Markdown bằng scripts/md2html.py; bản ghi governance/report chỉ có .md.

Sau:

  1. HTML là định dạng tài liệu duy nhất và là nguồn, sửa trực tiếp. Metadata của kit đặt trong <head> dạng <meta name="labelx:id|title|type|domain|module|tags|priority">.
  2. Mọi file .md trong docs/, .agent/ và ở gốc repo được chuyển sang HTML rồi xoá (157 file), kể cả AGENT.md → AGENT.html, template, bản ghi governance/report, file riêng theo người dùng (CR-100).
  3. Ngoại lệ do công cụ bắt buộc Markdown: CLAUDE.md, src/frontend/CLAUDE.md, src/frontend/AGENTS.md (Claude Code, Next.js), .agent/skills/labelx-design/SKILL.md (skill loader), README.md (trang repo GitHub), .github/pull_request_template.md (GitHub chỉ nhận Markdown/TXT).
  4. scripts/validate-framework.py đọc HTML qua scripts/kit_html.py; scripts/md2html.py bị xoá; scripts/srs_tex2md.py đổi thành scripts/srs_tex2docs.py, ghi thẳng HTML; CI bỏ bước kiểm HTML sinh từ Markdown.

Product Owner yêu cầu trong phiên làm việc ngày 2026-10-06: "Không thao tác bằng định dạng md nữa, chuyển hết sang html đi" và "Rồi xóa luôn các file md đi".
