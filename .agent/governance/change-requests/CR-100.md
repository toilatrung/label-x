## Proposed Change

Trước: mọi agent/dev có task được ghi trực tiếp vào các file dùng chung trong `.agent/` (ví dụ `.agent/execution/current-context.md`, `task-board.md`, `sessions-history.md`, `.agent/planning/*`, record governance/report).

Sau: dev và coding agent trên máy dev **không sửa file chính** trong `.agent/`. Mỗi người ghi vào file riêng cùng thư mục, tên `<tên-file-chính>-@<github-username>.<đuôi>` (ví dụ `.agent/execution/current-context-@dev1.md` và bản HTML sinh ra `current-context-@dev1.html`). Chỉ PO dự án Trịnh Quang Trung (`@toilatrung`) hoặc người được PO giao nhiệm vụ QC (liệt kê trong `.github/agent-integrators.txt`) mới được gộp nội dung các file riêng vào file chính và xoá file riêng đã gộp. Quy tắc được ghi vào `AGENT.md` (mục "Per-User Agent Files") và được CI kiểm trên mỗi pull request.

## Justification

Nhiều dev đẩy PR cùng lúc cùng sửa các file trạng thái dùng chung trong `.agent/` gây merge conflict lặp lại. File riêng theo người dùng loại bỏ việc hai PR cùng sửa một file; việc gộp tập trung ở một vai trò có quyền (PO/QC) giữ tính nhất quán của trạng thái chính.
