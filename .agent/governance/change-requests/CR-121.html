Proposed Change

Supersedes only CR-120's assumptions of existing application S3, existing CVAT and mandatory preconfigured off-VPS S3. Deploy one persistent SeaweedFS instance in the labelx namespace, three application buckets and distinct scoped application/admin credentials. CVAT uses pinned upstream v2.77.0 Compose on the existing Ubuntu host, behind K3s Traefik. No duplicate instance, additional LabelX environment or control-plane installation.

Allow explicit local-only encrypted PostgreSQL backup plus local persistent S3/CVAT data while offsite storage is unavailable. Local mode must report disaster recovery UNVERIFIED; daily offsite jobs stay suspended and pre-migration local backup must still restore a disposable DB. No fake endpoint, no skipped migration backup, no infinite retries for absent dependencies. Add offsite later through secret provisioning and a real restore drill. Existing production/MVP acceptance gates and CR-120's digest-only GitOps scope remain unchanged.

Justification

PO states in the current request that no S3 or offsite backup exists and asks for the necessary architecture/bootstrap changes, accurate local/offsite distinction, optional unconnected CVAT/GPU login and a concrete deployment handoff. This record captures that delegated implementation decision before baseline changes; it is not an agent-authored review signature.
