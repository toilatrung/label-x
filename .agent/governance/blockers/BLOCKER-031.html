Quy trình nối khi backend xong (dev bắt buộc theo)

  1. Xác nhận endpoint đã vào contract: docs/04-api/openapi.yaml và make gen-api sinh lại src/frontend/src/lib/api/contract.d.ts (commit cùng PR).
  2. Mở file ở cột "Vị trí trong code", thay nguồn dữ liệu minh họa (lib/mock/*, lib/*/sample-data.ts) bằng lời gọi API qua client sinh từ contract; xử lý loading, rỗng, lỗi (mã lỗi 400/403/404/409/422).
  3. Gỡ NotConnectedNotice và SampleDataBadge của vùng đã nối (chỉ vùng đó); bật nút ghi và kiểm quyền ở API; xoá dòng TODO(backend) tương ứng.
  4. Cập nhật test (xoá phần giả định minh họa, thêm test dữ liệu thật và lỗi), chạy scripts/frontend/check.sh (lint, test, build, verify-design), 3 bản CSS md5 trùng nếu đổi class.
  5. Tick cột "Đã nối" của dòng đó trong bản ghi này và ghi PR; khi mọi dòng nhóm B của một màn xong thì đóng task FE-11…FE-14 tương ứng.
  6. Không đổi contract trong PR frontend: endpoint mới/đổi hình dạng đi qua change request do PO duyệt.
