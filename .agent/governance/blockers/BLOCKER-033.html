Resolution Plan

VLM — Cấu hình kết nối tại Models và Guidelines (2026-10-14)

Theo chỉ đạo PO, VLM nằm trong bảng của tab Mô hình tại /configuration/guidelines; nút chỉnh sửa ở dòng VLM mở modal gồm model qwen3-vl-plus, Base URL, API key và ngưỡng tin cậy gọi VLM. GET/PATCH /api/configuration/vlm/ lưu phiên bản kết nối; QC Admin/Super Admin được sửa, QA Lead được xem. API key được mã hóa riêng bằng Fernet với khóa dẫn xuất từ Django deployment secret; worker và API phải dùng cùng DJANGO_SECRET_KEY. Khi xoay deployment secret, giữ khóa cũ trong SECRET_KEY_FALLBACKS cho các kết nối đã lưu.

  • Để trống API key khi lưu sẽ giữ key nếu Base URL không đổi; đổi Base URL yêu cầu key mới. API chỉ trả trạng thái đã có key; không trả plaintext/ciphertext. Audit chỉ ghi metadata công khai. Kiểm host/model theo allowlist hiện có.
  • Cấu hình QC mới bật VLM và không truyền models.vlm sẽ lấy kết nối hiện tại, đóng băng connection_id cùng thông tin model/provider. Replay cùng Idempotency-Key trả đúng phiên bản cũ dù kết nối hiện tại đã đổi. Run/cấu hình đã có không tự thay đổi.
  • Ngưỡng tin cậy trong modal và cột của bảng là ngưỡng score detector để gọi VLM, mặc định 0.85, miền [0, 1]; không phải confidence của kết quả VLM. Cấu hình QC mới bật VLM kế thừa vào thresholds.classification_routing.score_threshold khi không truyền ngưỡng riêng. Ngưỡng riêng của cấu hình QC có ưu tiên; cấu hình/run cũ giữ nguyên. Kiểm tra bổ sung: 86 test backend và 26 test frontend đã qua, gồm lưu ngưỡng, routing thay đổi theo ngưỡng và giữ bản cũ khi replay.
  • Worker lấy key từ kết nối đã tham chiếu, kiểm provider/model/Base URL/biến key khớp trước khi gọi provider. Publish cấu hình mới bật VLM mà thiếu kết nối bị từ chối 422 thay vì tiếp tục phát hành cấu hình dẫn tới no_model.
  • Kiểm thử: 221 test hồi quy VLM/orchestration và 39 test frontend đã qua; kiểm kiểu TypeScript/mypy và lint đã qua. Request provider dùng HTTP mock; chưa xác minh credential/quota hoặc kết quả Qwen thật.

Mã nguồn: form VLM, API cấu hình, credential và kết nối worker, kiểm thử tích hợp. Mục này vẫn open cho đến khi có bằng chứng run thật.
