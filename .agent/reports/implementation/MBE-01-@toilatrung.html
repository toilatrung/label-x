Scope

  • Implemented:
    • #289 Evaluation API ứng viên (POST /api/candidates/{id}/evaluations/, GET /api/candidate-evaluations/{id}/) đã có sẵn trên develop (PR #318/#330): đã kiểm lại 202 + poll URL, stale revision 409, key reuse 409 bằng test hiện có. Không sửa.
    • #290 Evidence AI trong workspace: GET /api/frames/{id}/workspace/ = frame issues + lease, queue, undecided_issue_count và ai_evidence[] (mỗi issue có candidate: source classifier|qwen, reason_code, reasons, review_required, suggestion, evidence_refs, evaluation mới nhất theo generation). Chỉ đọc; Qwen không tạo ReviewDecision/Adjudication.
    • GET /api/runs/{id}/lineage/: chuỗi original → rework_verification → final, final_run_id theo run cuối hợp lệ (tái dùng evaluate_operational_source).
    • Reference: POST /api/references/ (snapshot phải locked, idempotent), POST /api/references/{id}/lock/ (người khoá khác người lập GT kể cả cùng employee qua tài khoản khác → 403 SAME_REQUESTER_APPROVER; còn issue escalated chưa phân xử → 409; khoá lại là no-op).
    • KPI evaluation: POST /api/evaluations/ (202 + Location, reference phải locked 409, run/reference/snapshot phải cùng snapshot 422, run phải Completed 422, idempotent), GET /api/evaluations/{id}/.
    • Gate: GET /api/runs/{id}/gate/ — coverage, open_critical_issues (G-2 = 0), rework_verified, residual (G-4 ≤ 5%, lát random audit), agreement (G-3 ≥ 90%, reviewer vs DecisionCase); thiếu run cuối hợp lệ thì gate failed kèm source_reason.
    • Waiver: POST /api/waivers/ (chỉ coverage/agreement, hạn ở tương lai), POST /api/waivers/{id}/approve/ (người duyệt khác người đề nghị, chỉ hiệu lực sau duyệt và trước hạn; không biến run chưa Completed thành đạt).
    • Report: GET /api/reports/{id}/?format=json|csv (id = KPI evaluation).
    • Audit event cho reference.create/lock, kpi_evaluation.create, waiver.create/approve/reject.
  • Not Implemented: format=pdf trả 400 (chưa có thư viện PDF trong stack DEC-001); kiểm leakage held-out (leakage_check=not_checked); KPI-1/KPI-2/KPI-2b/G-1 (xem Known Limitations). Không sửa code frontend.
