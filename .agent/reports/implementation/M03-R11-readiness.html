M-03 R11 — Readiness môi trường E2E

Issue #247 (M03-R11). Hướng dẫn chạy script kiểm tra sẵn sàng (chỉ đọc) và danh sách đầu vào cần PO/Hà cung cấp. Script không tạo tài khoản/dữ liệu, không ghi DB/CVAT/storage, không in token hay mật khẩu.

  • Status: draft

Cách chạy

make infra-up
uv run --project src/backend python scripts/development/m03_readiness.py --out readiness.json

Script đọc src/backend/.env (và biến môi trường), chạy các kiểm tra rồi xuất JSON. Mã thoát: 0 = READY (mọi kiểm tra PASS); 1 = NOT_READY (có FAIL); 2 = BLOCKED (không FAIL nhưng còn BLOCKED/UNKNOWN). Tuỳ chọn --timeout (giây, mặc định 5).

Hạn chế

  • Readiness PASS không chứng minh E2E đạt; chỉ cho biết môi trường đủ điều kiện chạy.
  • Celery beat không có API ping nên chỉ suy ra gián tiếp (UNKNOWN nếu không có dấu hiệu).
  • Kiểm tra token CVAT dùng GET /api/users/self; không xác minh được token chỉ có quyền đọc — PO/Hà phải xác nhận.
  • Test của script dùng mock (src/backend/tests/test_m03_readiness_script.py), chưa chạy với dịch vụ thật trong phiên này.
