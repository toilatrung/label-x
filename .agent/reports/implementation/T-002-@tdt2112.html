Scope

  • Implemented:
    • Chọn và cấu hình test runner Vitest + React Testing Library + JSDOM cho frontend (triển khai phần test runner của BLOCKER-014); thêm lệnh npm test trong src/frontend/package.json.
    • Đưa npm test vào target test của scripts/init-develop-environment.mk (dành cho make check) và job frontend trong .github/workflows/ci.yml.
    • Dựng App Shell theo Design System LabelX với class chuẩn lx-*: TopBar (thanh điều hướng trên), ContextBar (thanh ngữ cảnh với chip Dataset, Guideline, Taxonomy, Run, Vai trò), FlowNav (điều hướng quy trình 3 bước), AppShell container.
    • Màn hình đăng nhập (/login) theo chuẩn Design System LabelX, hỗ trợ form đăng nhập và phím chọn nhanh 5 tài khoản mẫu cho các vai trò.
    • Hệ thống mock authentication API ban đầu: /api/auth/login (POST), /api/auth/me (GET), /api/auth/logout (POST) kèm quản lý cookie lx_session và localStorage. Phần này chưa khớp hợp đồng T-001 đã merge trong PR #21; cần cập nhật trước khi nghiệm thu.
    • Phân quyền hiển thị (RBAC) trên TopBar và Route Guard (AuthGuard): ẩn các mục không có quyền theo ma trận WorkflowPermissions.dc.html (ví dụ: Annotator không thấy Phân tích chất lượng và Review Center); chặn truy cập trái phép và hiển thị màn hình lỗi chuẩn 403 Forbidden (ForbiddenView) cùng mã lỗi FORBIDDEN.
    • Xử lý lỗi 401 Unauthorized tự động chuyển hướng về /login.
    • Bộ kiểm thử tự động gồm 4 file test (13 test cases) bao quát domain auth, component TopBar, LoginPage và AuthGuard/ForbiddenView.
    • Kiểm thử trực quan luồng thực tế bằng trình duyệt Chrome headless và ghi lại 4 ảnh chụp màn hình bằng chứng.
  • Not Implemented:
    • Chưa tích hợp client sinh từ OpenAPI T-001 và chưa căn chỉnh mock/session/RBAC theo docs/04-api/openapi.yaml, rbac-matrix.html trên develop sau PR #21. Đường dẫn, cookie, mã lỗi và dữ liệu session hiện còn khác hợp đồng.
    • Backend authentication và database thực tế bằng Django/PostgreSQL (thuộc phạm vi backend T-001/E-02).
    • Các màn hình nghiệp vụ chi tiết chuyên sâu (Dataset Explorer, Annotation Workspace, Rules Config Editor v.v. thuộc các task sau).
