Chạy metric trong WSL

Base origin/develop tại 24835df, nhánh fix/metric-engine. Docker dev chạy trong Ubuntu-24.04. Chạy migration backend trước khi khởi động worker mới.

docker compose -f infrastructure/docker-compose.dev.yml up -d --wait postgres redis seaweedfs
cd src/backend
uv run python manage.py migrate
uv run celery -A config worker -l info
uv run python manage.py metric_report RUN_ID

Upload GT vào bucket snapshots qua công cụ quản trị storage sẵn có. Tạo reference qua POST /api/references/: gt_source là object key, gt_checksum là SHA-256 của đúng byte JSON đã upload, algorithm_version=1.0.0, mapping version phải trùng ModelArtifact/manifest detector. QA Lead khác người tạo khóa reference qua API hiện có. Không đọc URL tùy ý hoặc file local từ gt_source.

{
  "schema_version": "labelx.metric.gt.v1",
  "snapshot_id": 123,
  "mapping_version": "bdd100k-det-10-v1",
  "frames": [{
    "cvat_task_id": 9, "frame_number": 0,
    "slices": ["day", "clear"],
    "boxes": [{"id": "gt-1", "label": "car", "bbox_xyxy": [0, 0, 10, 10], "ignored": false}]
  }]
}

Class là tên canonical BDD100K, không dùng CVAT label ID. Frame có boxes=[] là GT hợp lệ không có vật thể; bỏ frame là thiếu GT. Ignore và minimum_area áp dụng cho GT trước matching. Sai lớp sau ghép hình học tính FN cho lớp GT và FP cho lớp dự đoán. Mẫu số 0 trả null; tổng hợp cộng TP/FP/FN rồi tính tỷ lệ, không lấy trung bình tỷ lệ frame.

Cấu hình đã publish cần chọn model artifact bằng name/version và reference ID cố định:

{
  "engines": {"metric": {"enabled": true, "params": {"reference_id": 456}}},
  "models": {"name": "registered-detector-name", "version": "registered-version"}
}

GT thiếu/chưa khóa/khác snapshot trả not_checked/no_reference; checksum/schema/mapping sai làm task failed. Thiếu model được planner ghi not_checked/no_model. Ledger details và counts được commit cùng transaction với ShardCommit; giao lại không nhân kết quả. metric_report hiển thị coverage, trạng thái từng frame, provenance, Precision/Recall theo lớp/slice; khi coverage thiếu, số metric chỉ là phần đã hoàn thành.
