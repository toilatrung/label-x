Scope

  • Nạp mapping nhóm lỗi/lớp → rule ID từ tệp YAML, idempotent theo checksum SHA-256 (CR-101).
  • Kiểm tra tính hợp lệ khi nạp: rule ID tồn tại trong guideline; class_name và paired_class thuộc taxonomy 10 lớp BDD100K; family thuộc enum IssueFamily; không trùng bộ selector. Lỗi từ chối toàn bộ file theo cơ chế all-or-nothing (CR-107).
  • Lệnh nạp bắt buộc --actor <username>; kiểm tra tài khoản tồn tại, kích hoạt và có vai trò quản trị (QC_ADMIN hoặc SUPER_ADMIN).
  • Mỗi lần nạp lưu bản ghi bất biến GuidelineLoadRecord (actor, thời điểm, SHA-256, số dòng, kết quả, mảng lỗi chi tiết theo dòng). Chặn cập nhật và xóa qua model, custom queryset và Django admin.
  • API đọc mapping GET /api/guidelines/mappings/ hỗ trợ lọc (family, class_name, paired_class, version) và phân trang con trỏ (cursor pagination). Quyền đọc tuân thủ ma trận RBAC (reviewer, qa_lead, qc_admin, super_admin); cấm các phương thức ghi (POST, PUT, PATCH, DELETE trả về 405).
  • Màn hình RulesThresholds chỉ xem, hiển thị dữ liệu mapping từ API, hỗ trợ phân trang trước/sau bằng cursor, hiển thị trạng thái loading/empty/error an toàn, chặn truy cập khi thiếu quyền qua AuthGuard.
