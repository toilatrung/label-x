Objective

Workspace tra được rule theo rule ID từ guideline tĩnh nạp từ tệp (thay FR-GDL-01…03 theo CR-101), không dùng retrieval ngữ nghĩa (FR-GDL-04 Must).

Các điểm sửa đổi theo Review T-003 (Revision 2)

Bản sửa đổi đã cập nhật toàn diện cả backend và frontend theo review chi tiết:

  1. Backend Error Contract & Request ID:
    • Thêm RequestIDMiddleware (src/backend/config/middleware.py) để quản lý header X-Request-ID và gán request_id thống nhất cho toàn bộ phản hồi lỗi.
    • Thêm custom_exception_handler dùng chung (src/backend/config/exceptions.py) chuẩn hóa mã lỗi: NOT_FOUND, FORBIDDEN, NOT_AUTHENTICATED, VALIDATION_ERROR theo format {"code", "message", "details", "request_id"}. Bỏ exception handling cục bộ trong view.
  2. Backend RBAC & Permissions:
    • Thêm permission HasGuidelineRole (src/backend/guideline/permissions.py) cho phép 4 vai trò: reviewer, qa_lead, qc_admin, super_admin; từ chối người dùng annotator hoặc user thường với HTTP 403 FORBIDDEN.
    • Ghi chú kiến trúc: Hệ thống RBAC hiện tại sử dụng Django group tạm thời trong giai đoạn pilot theo ma trận quyền.
  3. Backend Query & Pagination:
    • Đổi query parameter error_group thành family, kiểm tra enum nghiêm ngặt (E1, E2, E3, structural), trả 400 VALIDATION_ERROR nếu sai enum.
    • Xử lý wildcard mapping: mapping có trường rỗng hoạt động như wildcard khớp mọi class_name / paired_class; bỏ qua query parameter rỗng.
    • Áp dụng CursorPagination (PAGE_SIZE=50) với response envelope {"next", "previous", "results"}, không có trường count.
    • Loại bỏ endpoint /api/guidelines/ không thuộc OpenAPI contract chung. Frontend lấy guideline_version từ kết quả rules.
    • Sửa hàm get_latest_guideline_version() chọn theo số trong version_tag, không phải loaded_at.
  4. Frontend Alignment & Clean Design:
    • Sử dụng contract type chính thức contract.d.ts từ T-001; xóa hoàn toàn file schema.d.ts tự viết.
    • Bỏ toàn bộ lời gọi GET /api/guidelines/; frontend gọi GET /api/guidelines/rules/ và hiển thị version lấy từ bản ghi rule.
    • Bỏ gọi setSelectedTag trong render body.
    • Dùng thuộc tính chuẩn aria-selected="true" cho dòng đang chọn thay vì inline background style.
    • Đổi nhãn trạng thái từ “Đang dùng” thành “Mới nhất”.
    • Bỏ colSpan={99}, dùng đúng số cột (4 cột cho bảng version, 3 cột cho bảng rules).
    • Loại bỏ 100% style={{...}} trong page.tsx, ưu tiên class lx-* có sẵn và bổ sung tối thiểu các class lx-guideline-* trong globals.css.
    • Ưu tiên nhận diện error code NOT_AUTHENTICATED (kể cả khi backend trả 403) và FORBIDDEN để hiển thị thông báo đăng nhập / quyền rõ ràng.
