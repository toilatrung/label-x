Bằng chứng kiểm tra thủ công (bàn giao từ Codex)

Lưu ý về nguồn gốc bằng chứng: Toàn bộ các xác minh dưới đây là bằng chứng bàn giao từ Codex qua kiểm tra môi trường local, không phải do agent Antigravity tự thực hiện.

  • Database Migration: Lệnh python manage.py migrate đã chạy thành công, tạo đầy đủ bảng guideline_guidelineversion, guideline_guidelinerule, guideline_rulemapping.
  • Guideline Ingestion & Idempotency: Lệnh python manage.py load_guideline src/backend/fixtures/bdd100k_guideline_v1.yaml đã nạp thành công 13 rule và các mapping group. Khi chạy lại lần hai với cùng tệp, command bỏ qua chính xác theo SHA-256 checksum mà không tạo trùng bản ghi.
  • Xác thực API & Quyền:
    • GET /api/guidelines/rules/VEH-01/ khi đã đăng nhập (authenticated): trả về HTTP 200 OK với đúng payload rule và version.
    • GET /api/guidelines/rules/VEH-01/ khi chưa đăng nhập (unauthenticated): trả về HTTP 403 Forbidden kèm hợp đồng lỗi {"code": "forbidden", "message": "...", "request_id": "..."}.
  • Trình duyệt Frontend: Codex đã kiểm tra trực tiếp trên trình duyệt local tại đường dẫn http://localhost:3000/configuration/guidelines. Kết quả: trang hiển thị phiên bản v1, hiển thị đủ 13 rules trong bảng dữ liệu, và không có bất kỳ cảnh báo hoặc lỗi nào trong DevTools Console.

Quyết định thiết kế

  • Định dạng tệp YAML: YAML dễ soạn thảo thủ công cho QA Lead, hỗ trợ block scalar cho nội dung văn bản dài.
  • Idempotency bằng SHA-256: Kiểm tra trùng hash tệp để bỏ qua nạp lại, ngăn chặn ghi đè version_tag đã có với nội dung khác.
  • Thông báo stdout và exception tiếng Anh: Giữ nguyên tiếng Anh trong load_guideline.py để tránh lỗi UnicodeEncodeError trên Windows console.
  • Chỉ đọc, không có UI chỉnh sửa guideline: Tuân thủ CR-101 (hoãn scope FR-GDL-01…03); pilot chỉ phục vụ tra cứu.
  • Type an toàn sinh từ OpenAPI: Frontend dùng schema.d.ts được sinh tự động bởi npm run gen:api; tệp guideline-types.ts stub ban đầu đã được xóa bỏ để bảo đảm một nguồn sự thật duy nhất (DEC-001).
  • Khai báo PyYAML tường minh: pyyaml và types-pyyaml đã được thêm trực tiếp vào pyproject.toml.
