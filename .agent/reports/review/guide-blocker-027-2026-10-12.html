Mục 1. Shape bị bỏ qua trên CVAT thật

Cơ sở: cvat_adapter/hashing.py chỉ băm rectangle. Mọi shape khác (polygon, polyline, points, ellipse, skeleton) và track không hợp lệ được đếm vào ignored_shape_count / ignored_track_count. Dữ liệu learner toàn bbox nên hiện luôn bằng 0.

  1. Trong CVAT (http://localhost:8080), tạo project và task riêng để thử, không đụng dữ liệu learner. Có thể dùng project labelx-dev hoặc ảnh BDD100K bạn đã có. Nhãn cần loại Polygon hoặc Any.
  2. Mở Job, vẽ 1 rectangle và 2 polygon trên cùng một ảnh, bấm Save. Ghi Project ID, Task ID, Job ID.
  3. Gán qa_lead cho Dataset (Project ID): cd src/backend && uv run --frozen python manage.py assign_role qa_user qa_lead --dataset-id <PROJECT_ID>
  4. Kiểm nhanh số shape bị bỏ qua: make cvat-hash JOB_ID=<id>. Kỳ vọng ignored_shape_count = 2 và rectangles = 1.
  5. Trên LabelX, mở /analysis, chọn Dataset, Job, tạo Snapshot, đợi trạng thái locked, mở chi tiết Snapshot. Kỳ vọng ô “shape bị bỏ qua” hiển thị 2, và Snapshot vẫn khoá bình thường.
  6. Chụp ảnh chi tiết Snapshot và lưu output bước 4.

Đạt khi: số shape bị bỏ qua trên UI và trên cvat-hash cùng bằng số polygon đã vẽ. Nếu UI hiện 0 trong khi CVAT có polygon thì là FAIL, cần ghi nguyên văn.

Mục 2. CSRF, Idempotency-Key khi tạo Snapshot qua UI và deep link

  1. Mở DevTools, tab Network, chọn Preserve log. Đăng nhập qa_user, mở /analysis.
  2. Chọn Dataset, Job, bấm tạo Snapshot. Trong request POST /api/snapshots/ kiểm: status 201 (không có lỗi CORS / “Không kết nối được máy chủ”), header X-CSRFToken có giá trị, header Idempotency-Key có giá trị. Chụp ảnh tab Headers.
  3. Idempotency: bấm tạo lại cùng lựa chọn (hoặc gửi lại request bằng “Replay XHR”). Kỳ vọng không sinh bản ghi Snapshot trùng; /analysis/snapshots chỉ có 1 bản ghi cho lần đó.
  4. CSRF thiếu token: curl -i -X POST http://localhost:8000/api/snapshots/ -H "Content-Type: application/json" -d '{}' kỳ vọng 403. Body hợp lệ lấy trong docs/04-api/openapi.yaml, không đoán.
  5. Deep link: trong chi tiết Snapshot, bấm “Mở Job CVAT” và “Mở Frame”. Kỳ vọng mở đúng Job và đúng frame trong CVAT. Chụp URL và màn CVAT.
  6. Deep link Dataset khác: đang chọn Dataset A, mở /analysis?snapshotId=<id của Dataset B>. Kỳ vọng thanh ngữ cảnh đổi đúng sang Dataset B.

Đạt khi: 201, có cả hai header, không trùng bản ghi, thiếu CSRF bị 403, hai deep link đúng.
