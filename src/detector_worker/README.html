Wayback chỉ là nguồn phục hồi; runtime phải dùng bản đã xác minh trong kho artifact nội bộ.

Build image

Backend trên host → warm worker (BLOCKER-033)

Django/Celery không cài torch và không gọi CLI trong host nữa. Backend gửi byte ảnh qua HTTP tới worker đã nạp model; không gửi đường dẫn host vào container. CLI infer/verify/fetch vẫn dùng được độc lập để quản lý artifact và chạy offline.

  1. Đặt checkpoint đã verify ở host (không commit file .pth). Trong Ubuntu/WSL dùng đường dẫn Linux; trong Windows dùng đường dẫn Windows. Không dùng /models/... hay /app/... làm đường dẫn của backend host.
  2. Khởi tạo src/backend/.env bằng make env nếu chưa có. Từ root repo chạy: 
    uv run --project src/backend --frozen python scripts/development/detector_runtime.py configure \
  --checkpoint /absolute/host/path/faster_rcnn_r50_fpn_3x_det_bdd100k.pth
make detector-up
make detector-check
make detector-register

    configure chỉ cập nhật các biến detector trong .env local, sinh token ngẫu nhiên khi chưa có, không in token. detector-up build image, mount thư mục checkpoint read-only, bật GPU nếu device là cuda, chờ model đã nạp và HTTP health thành công. Muốn CPU đặt DETECTOR_DEVICE=cpu trong .env trước khi up. Checkpoint, manifest và Config MMDetection trong image phải đồng bộ với checkout backend.

  3. detector-register xác minh SHA-256/checkpoint, manifest 10 lớp, version và worker trước khi đăng ký ModelArtifact. Chạy lại idempotent; artifact khác checksum/class map không bị ghi đè. Lệnh detector-check chỉ đọc, không ghi DB.
  4. Tạo/publish ConfigVersion mới, bật engines.detector.enabled=true, và đặt models bằng đúng cặp name/version lệnh register in ra. Không đưa token hay đường dẫn vào ConfigVersion. Không tự sửa cấu hình đã publish. Tạo run mới trên snapshot locked rồi kiểm tra detector checked, completed_units bằng eligible_units và failed_units=0. Run cũ no_model không được viết lại: thiếu ModelArtifact trong cấu hình thì backend vẫn giữ no_model, không giả success.
  5. Chạy Celery bằng make dev-worker (khởi động lại nếu vừa đổi .env), xem log bằng make detector-logs; tắt riêng detector bằng make detector-down, không xoá checkpoint hay DB.

Chỉ publish 127.0.0.1:8501. Mọi request health/infer cần Bearer token; backend không dùng proxy môi trường hay follow redirect. Không expose worker qua HTTP công khai; môi trường nhiều máy cần HTTPS/mTLS do vận hành triển khai trước. Request tối đa 70 MiB, tối đa 256 ảnh; giảm shard_size nếu shard ảnh vượt giới hạn. Batch GPU mặc định 1 (tối đa 4), một request inference tại một thời điểm.

Preflight lỗi: kiểm tra Docker/NVIDIA, checkpoint host tồn tại, token >=32 ký tự, worker healthy, và cấu hình models trỏ đúng ModelArtifact. not_checked/no_model khác với lỗi HTTP worker: lỗi HTTP không được biến thành checked. Không kết luận accuracy, calibration hay quality gate từ smoke một frame.

Build image offline CLI

make detector-image

# Máy dùng Docker Engine CLI trong WSL
wsl -d Ubuntu-24.04 -- bash -lc \
  'cd /mnt/d/Code/label-x && make detector-image'

Image pin PyTorch 1.12.1, CUDA 11.3, mmcv-full 1.7.1 và MMDetection 2.28.2. Có thể chạy không gắn GPU bằng --device cpu. Trước khi dùng --gpus all, kiểm tra docker info có runtime NVIDIA/CDI và chạy thử docker run --rm --gpus all nvidia/cuda:11.3.1-base-ubuntu20.04 nvidia-smi.

Freeze artifact đã phục hồi

docker run --rm -v /secure/models:/models -v "$PWD/src/detector_worker:/work" \
  labelx-detector-worker:dev freeze \
  --checkpoint /models/faster_rcnn_r50_fpn_3x_det_bdd100k.pth \
  --manifest /work/model-manifest.json

Lệnh ghi SHA-256, kích thước, tên file và thời điểm freeze bằng thao tác thay file nguyên tử. Manifest hiện tại đã freeze file 165.899.860 byte; lệnh verify luôn chạy trước khi MMDetection deserialize checkpoint.

Publish/fetch kho artifact S3-compatible

export AWS_ACCESS_KEY_ID='<access-key>'
export AWS_SECRET_ACCESS_KEY='<secret-key>'

labelx-detector publish \
  --checkpoint /secure/models/faster_rcnn_r50_fpn_3x_det_bdd100k.pth \
  --manifest model-manifest.json \
  --endpoint "$MODEL_ARTIFACT_ENDPOINT" --bucket labelx-models \
  --key detector/syscv-bdd100k-models-0935a8a3/ba1be4c41669969ff89083a9ac9355a5fdd81505786d9b5eb3a5126a4d053540/faster_rcnn_r50_fpn_3x_det_bdd100k.pth

labelx-detector fetch \
  --checkpoint /models/faster_rcnn_r50_fpn_3x_det_bdd100k.pth \
  --manifest model-manifest.json \
  --endpoint "$MODEL_ARTIFACT_ENDPOINT" --bucket labelx-models \
  --key detector/syscv-bdd100k-models-0935a8a3/ba1be4c41669969ff89083a9ac9355a5fdd81505786d9b5eb3a5126a4d053540/faster_rcnn_r50_fpn_3x_det_bdd100k.pth

publish xác minh file local trước khi PUT, ghi metadata x-amz-meta-sha256 và HEAD kiểm lại kích thước/checksum. fetch tải về file tạm, kiểm SHA-256 rồi mới thay file đích nguyên tử. Credentials chỉ lấy từ environment; không ghi trong manifest hay log. Stack dev tạo bucket labelx-models trên SeaweedFS S3-compatible; production dùng endpoint/credentials do Operations cấp.

Verify và inference

docker run --rm --gpus all \
  -v /secure/models:/models:ro -v /bdd-samples:/input:ro -v /tmp/labelx-out:/output \
  labelx-detector-worker:dev verify \
  --checkpoint /models/faster_rcnn_r50_fpn_3x_det_bdd100k.pth \
  --manifest model-manifest.json

docker run --rm --gpus all \
  -v /secure/models:/models:ro -v /bdd-samples:/input:ro -v /tmp/labelx-out:/output \
  labelx-detector-worker:dev infer \
  --input-dir /input --output /output/predictions.json \
  --checkpoint /models/faster_rcnn_r50_fpn_3x_det_bdd100k.pth \
  --manifest model-manifest.json \
  --config configs/faster_rcnn_r50_fpn_3x_det_bdd100k.py \
  --device cuda:0 --batch-size 1

Để thử CPU, bỏ --gpus all và dùng --device cpu. JSON chứa schema version, model/checksum/mapping, cấu hình run, phần cứng, thời gian tổng và mỗi ảnh, kích thước ảnh, detection và confidence.

MX330 2 GB đã được xác minh với --batch-size 1. Không tải checkpoint trực tiếp từ Wayback trong runtime; dùng fetch từ kho artifact, sau đó mount file đã xác minh vào /models dưới dạng chỉ đọc.
